# Milestone 0: Repository Setup

## Goal

Create the initial repository skeleton for a staged WSSV phylotyping project without implementing analysis logic.

## Expected Inputs

- Existing project concept and roadmap.
- Current exploratory SNP-scoring script as background only.
- No raw data files are required for this milestone.

## Expected Outputs

- Project documentation.
- Placeholder configuration.
- Placeholder workflow scripts.
- Placeholder R function files.
- Data and output directory conventions.
- Initial test file placeholders.

## Success Criteria

- All requested files and directories exist.
- Raw data directories contain README files only.
- Generated-output directories are ignored by Git while retaining `.gitkeep` files.
- Placeholder scripts and function files do not contain full analysis logic.
